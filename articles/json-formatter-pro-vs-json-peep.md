## Frequently Asked Questions

**What is JSON Peep and how does it format JSON?**
JSON Peep is a lightweight Chrome extension that pretty-prints raw JSON responses directly in the browser tab. It offers basic tree visualization and is designed for developers who want minimal overhead without extra features like search or validation.

**Is JSON Peep a lightweight alternative to JSON Formatter Pro?**
Yes. JSON Peep has a significantly smaller footprint than JSON Formatter Pro (738KiB). If you only work with small JSON payloads and don't need syntax themes or regex search, JSON Peep covers basic needs without adding much to your browser's memory usage.

**Which is better for quick JSON previews: JSON Peep or JSON Formatter Pro?**
For very quick, one-off previews of small JSON files, either extension works. For anything over 100KB, or if you need to search within the output, JSON Formatter Pro's performance and search capabilities make it the faster option in practice.

**Can JSON Peep search within JSON like JSON Formatter Pro?**
JSON Peep offers only basic text search. JSON Formatter Pro supports advanced regex-based search, which is essential when working with large API responses or when looking for specific keys across deeply nested objects.
